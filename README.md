# Zalo Fake Chat Preview

Một trang web mô phỏng giao diện tin nhắn Zalo với khung soạn thảo và bản xem trước trực quan.

## Preview
Mở file `index.html` trong trình duyệt hoặc truy cập GitHub Pages sau khi repo được triển khai.

## Tính năng
- Thay đổi ảnh đại diện
- Sửa tên người gửi
- Tùy chỉnh nhà mạng, pin, giờ, giao diện
- Cập nhật nội dung tin nhắn
- Lưu nhanh mẫu dữ liệu vào localStorage
